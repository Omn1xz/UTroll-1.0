# UTroll

Плагин для троллинга игроков на сервере Minecraft Paper 1.21.4.

## Требования

- Java 21
- Paper 1.21.4
- ProtocolLib (опционально, требуется для команды crash)

## Установка

1. Скачайте плагин UTroll
2. Поместите файл .jar в папку `plugins` вашего сервера
3. (Опционально) Установите ProtocolLib для работы команды crash
4. Перезапустите сервер
5. Настройте конфигурацию в `plugins/UTroll/config.yml`

**Примечание:** Команда `/troll <nick> crash` требует установленный ProtocolLib. Если ProtocolLib не установлен, эта команда не будет работать.

## Команды

- `/troll help` - Показать справку по командам
- `/troll <nick> launch` - Подкинуть игрока в воздух
- `/troll <nick> crash` - Крашнуть клиент игрока
- `/troll <nick> rotate` - Вращать камеру игрока
- `/troll <nick> invdrop` - Выбросить инвентарь игрока
- `/troll <nick> badeffects` - Выдать плохие эффекты
- `/troll <nick> rtp` - Случайные телепортации
- `/troll <nick> down` - Телепортировать вниз
- `/troll <nick> spam` - Спамить игроку
- `/troll <nick> holo <on/off>` - Голограмма над головой
- `/troll <nick> allahackbar` - TNT за игроком

## Права

- `utroll.troll` - Позволяет использовать все команды тролля (по умолчанию: op)

## Конфигурация

```yaml
troll:
  launch-blocks: 25        # Высота подкидывания игрока (в блоках)
  rotate-timer: 15         # Длительность поворотов камеры (в секундах)
  badeff-timer: 15         # Длительность плохих эффектов (в секундах)
  rtp:
    blocks: 10             # Дальность телепортов от исходной точки (в блоках)
    timer: 15              # Длительность (в секундах)
  down-blocks: 3           # На сколько игрока телепортирует вниз (в блоках)
  spam-timer: 15           # Длительность спама (в секундах)
```

## Сборка

Для сборки плагина используйте Maven:

```bash
mvn clean package
```

Готовый файл будет находиться в папке `target`.
