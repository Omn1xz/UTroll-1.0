# UTroll

Плагин для троллинга игроков на сервере Minecraft Paper 1.21.4.

## Требования

- Java 21
- Paper 1.21.4
- ProtocolLib (опционально, требуется для команд crash и spam)

## Установка

1. Скачайте плагин UTroll
2. Поместите файл .jar в папку `plugins` вашего сервера
3. (Опционально) Установите ProtocolLib
4. Перезапустите сервер
5. Настройте конфигурацию в `plugins/UTroll/config.yml`

**Примечание:** Команды `/troll <nick> crash` и `/troll <nick> spam` требуют установленный ProtocolLib. Если ProtocolLib не установлен, эти команды не будут работать.

## Команды

### `/troll help`
Показывает инфу о всех командах.

### `/troll <nick> launch`
Подкидывает выбранного игрока в воздух на высоту.

### `/troll <nick> crash`
Крашнет клиент выбранного игрока через отправку большого количества пакетов. Требует установленный ProtocolLib.

### `/troll <nick> rotate`
Начинает вращать камеру выбранного игрока в случайные стороны.

### `/troll <nick> invdrop`
Постепенно выбрасывает все предметы из инвентаря выбранного игрока на землю.

### `/troll <nick> badeffects`
Применяет все плохие эффекты зелий к выбранному игроку одновременно: слепота, иссушение, замедление, усталость при копании, тошнота, отравление, мгновенный урон, слабость, голод и темнота.

### `/troll <nick> rtp`
Начинает телепортировать выбранного игрока в случайные места в радиусе, указанном в конфигурации (по умолчанию 10 блоков) от исходной точки.

### `/troll <nick> down`
Телепортирует выбранного игрока вниз на указанное количество блоков от его текущей позиции (по умолчанию 3 блока).

### `/troll <nick> spam`
Спамит выбранному игроку через пакеты ProtocolLib и длинные тексты в title, action bar и чате. Требует установленный ProtocolLib.

### `/troll <nick> holo <on/off>`
Заспавнит или уберёт голограмму над головой выбранного игрока с текстом, указанным в конфигурации (по умолчанию "§e↓ Опущенный позорник ↓").

### `/troll <nick> allahackbar`
Заспавнит указанное в конфигурации количество TNT (по умолчанию 1) над головой выбранного игрока. TNT следует за игроком и взрывается через 4 секунды.

### `/troll <nick> magnet <on/off>`
Притягивает выбранного игрока к вам, если вы находитесь в радиусе 30 блоков. Игрок будет постоянно двигаться в вашу сторону с определённой скоростью. Работает только если вы с клиента, а не консоли.

## Права

- `utroll.troll` - Позволяет использовать все команды тролля (по умолчанию: op)

## Конфигурация

```yaml
troll:
  launch-blocks: 25        # Высота подкидывания игрока (в блоках)
  rotate-timer: 15         # Длительность поворотов камеры (в секундах)
  badeff-timer: 15         # Длительность плохих эффектов (в секундах)
  rtp:
    blocks: 10             # Дальность телепортов от исходной точки (в блоках)
    timer: 15              # Длительность (в секундах)
  down-blocks: 3           # На сколько игрока телепортирует вниз (в блоках)
  spam-timer: 15           # Длительность спама (в секундах)
  hologram: "§e↓ Опущенный позорник ↓"  # Текст голограммы над головой игрока
  allahakbar: 1            # Количество TNT для allahackbar команды
```

## Сборка

Для сборки плагина используйте Maven:

```bash
mvn clean package
```

Готовый файл будет находиться в папке `target`.
